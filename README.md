# ColorGrade

**Android photo color grading app** — ubah warna foto secara cepat dan mudah.

Fitur pengaturan warna:
- ☀️ **Brightness** (kecerahan)
- 🌗 **Contrast** (kontras)
- 🎨 **Saturation** (saturasi)
- 🌡️ **Temperature** (suhu warna)
- 🔵 **Tint** (rona)

---

## 📲 Download APK

Pasang langsung di HP Android kamu. Aktifkan **"Install from unknown sources"** jika diminta.

[⬇️ **Download ColorGrade.apk**](ColorGrade.apk)

---

## 🛠️ Build dari source code

```bash
# Pastikan sudah ada JDK & Android SDK
./gradlew assembleDebug
```

Hasil build: `app/build/outputs/apk/debug/app-debug.apk`
